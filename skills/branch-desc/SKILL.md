# /branch-desc — Описание изменений в ветке

Аргументы: `$ARGUMENTS` — базовая ветка (по умолчанию — основная ветка репозитория: `main`/`master`/`develop`, смотри что реально используется в проекте через `git branch -a` или `CLAUDE.md`).

---

## Алгоритм

1. Определи базовую ветку: если аргумент передан — используй его, иначе основную ветку разработки этого репозитория.

2. Получи список коммитов и статистику изменений:
   ```bash
   git log <base>..HEAD --oneline
   git diff <base>...HEAD --stat
   ```

3. Для понимания сути изменений быстро просмотри ключевые изменённые файлы — особенно новые модули бизнес-логики, сервисы, модели, фоновые задачи. Не читай всё подряд — только то, что нужно для понимания смысла.

4. Напиши описание.

---

## Формат описания

**Плоский список строк, без заголовков, без блоков, без markdown-форматирования.**

Каждая строка — одно смысловое изменение. Порядок: от самого значимого к менее значимому.

Правила:
- Язык: русский
- Стиль: "Добавлен X", "Исправлено Y", "Вынесено Z в отдельный модуль"
- Тире для уточнения: "Добавлена фоновая задача complete_orders — переводит заказ в статус «Завершён»"
- Никаких bullet-точек, жирного текста, заголовков
- Максимум 10–12 строк, не раздувать
- Мелкие сопутствующие изменения (lint, импорты, минорные рефакторы) — объединяй или опускай
- Технические детали — только если они значимы для понимающего разработчика

## Пример

```
Добавлена фоновая задача complete_orders — переводит заказ и позицию в статус «Завершён» по окончании доставки
Заказ переводится в «Завершён» только при полной доставке, не частичной
Добавлен ChangeOrderStatusService — смена статуса заказа в ходе обработки
Добавлен сервис финализации плана возврата по завершении проверки
Добавлены сигналы на удаление заказа и позиции для пересчёта остатков
CommandViewSet разовых команд вынесен в отдельный файл с политиками доступа
Удалены legacy_sessions.py, async_db_methods.py — логика поглощена consumer_sessions.py
Добавлен OneTimeCommandSerializer и схема команд для документации API
Добавлена поддержка уведомлений в WebSocket-потоке заказов
Добавлена админка для заказов и расширена админка для позиций
```
